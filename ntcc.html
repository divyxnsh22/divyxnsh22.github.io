Real-Time Satellite Signal Quality Monitoring Using IoT Sensors and Anomaly Detection

NTCC Research Project • Summer 2026

Abstract

This project develops a data-driven framework for monitoring satellite signal quality in real time using IoT telemetry streams and machine learning based anomaly detection techniques.

Research Objectives

  • Monitor satellite signal quality continuously
  • Simulate IoT telemetry streams
  • Detect anomalies using machine learning
  • Build a scalable monitoring framework
  • Create visualization dashboards

Technology Stack

  • Python
  • Pandas
  • NumPy
  • Scikit-Learn
  • Matplotlib
  • Jupyter Notebook
  • NASA/Kaggle Datasets
